## MCP-docs

В разделе описан MCP-сервер документации JSON API Remap 1.2. После подключения ИИ-агент может искать ответы по этой документации: находить эндпоинты, поля сущностей, параметры запросов и ограничения.
Сервер не выполняет запросы к пользовательскому аккаунту МоегоСклада. Он только читает документацию.

Зачем подключать MCP-сервер

- Агент запрашивает только фрагмент документации, нужный для текущего вопроса
- Ответы получаются быстрее и с меньшим расходом токенов
- В чат попадает уже найденный фрагмент, а не набор файлов целиком
- MCP-сервер читает актуальную документацию Remap 1.2

### Подключение

Настройки схожи для любого ИИ-агента, который имеет возможность подключать удаленные MCP-серверы.


| Параметр        | Значение                                    |
| --------------- |---------------------------------------------|
| **Имя сервера** | Любое, например `moysklad-docs`             |
| **URL**         | `https://mcp.moysklad.ru/doc/api/remap/1.2` |
| **Авторизация** | Не требуется.                               |


#### Варианты подключения MCP-сервера

##### Попросить агента подключить сервер

В чате попросите агента добавить MCP-сервер документации и передайте ему настройки:

- имя: Любое, например `moysklad-docs` 
- URL: `https://mcp.moysklad.ru/doc/api/remap/1.2`
- авторизация не требуется

После добавления проверьте, что сервер появился в списке MCP и включен. Если статус не обновился, перезапустите клиент. При первом обращении разрешите вызов, если агент запросит подтверждение.

##### Ввести настройки самостоятельно

В настройках агента откройте раздел MCP, плагинов или подключений и добавьте новый сервер. Укажите те же параметры:

- имя: `moysklad-docs`
- URL: `https://mcp.moysklad.ru/doc/api/remap/1.2`
- авторизация не требуется

>Пример:
```json
{
  "mcpServers": {
    "moysklad-docs": {
      "url": "https://mcp.moysklad.ru/doc/api/remap/1.2"
    }
  }
}
```

Сохраните настройки и убедитесь, что сервер включен. Если клиент хранит MCP в конфигурационном файле, добавьте туда запись с этими же именем и URL.

#### Как использовать MCP-сервер

После подключения достаточно сформулировать задачу в чате. Агент сам найдет нужные фрагменты документации. 

Примеры:

- `Найди в документации Remap 1.2, как создать Товар. Нужны путь, метод и обязательные поля.`
- `Какие фильтрамы и параметры доступны в запросе Заказа покупателя?`
- `Нужна последовательность запросов: создать Контрагента и затем создать Заказ покупателя.`

Если ответ агента расходится с документацией, ориентируйтесь на документацию.
