## MCP-dev

В разделе описан MCP-сервер для документации JSON API Remap 1.2. После подключения ИИ-агент может искать ответы по этой документации: находить эндпоинты, поля сущностей, параметры запросов и ограничения.
Сервер не выполняет запросы к пользовательскому аккаунту МоегоСклада. Он только читает документацию.

Зачем подключать MCP-сервер

- Агент запрашивает только фрагмент документации, нужный для текущего вопроса
- Ответы получаются быстрее и с меньшим расходом токенов
- В чат попадает уже найденный фрагмент, а не набор файлов целиком
- Агент работает с актуальной документацией JSON API 1.2

### Подключение

Настройки схожи для любого ИИ-агента, который поддерживает подключение удаленных MCP-серверов.

| Параметр        | Значение                                    |
| --------------- |---------------------------------------------|
| **Имя сервера** | Любое, например `moysklad-docs`             |
| **URL**         | `https://mcp.moysklad.ru/doc/api/remap/1.2` |
| **Авторизация** | Не требуется                                |

#### Варианты подключения MCP-сервера

##### Попросить агента подключить сервер

В чате попросите агента добавить MCP-сервер документации и передайте ему имя сервера и URL из таблицы.

##### Ввести настройки самостоятельно

В настройках агента откройте раздел MCP, плагинов или подключений и добавьте новый сервер с именем и URL из таблицы. В зависимости от ИИ-агента настройки вводятся в поля формы или в JSON-файл.

>Пример:
```json
{
  "mcpServers": {
    "moysklad-docs": {
      "url": "https://mcp.moysklad.ru/doc/api/remap/1.2"
    }
  }
}
```

##### После подключения

Проверьте, что сервер появился в списке MCP и включен. Если статус не обновился, перезапустите клиент. При первом обращении разрешите вызов, если агент запросит подтверждение.

#### Как использовать MCP-сервер

После подключения достаточно сформулировать задачу в чате. Агент сам найдет нужные фрагменты документации.

Примеры:

- `Найди в документации Remap 1.2, как создать Товар. Нужны путь, метод и обязательные поля.`
- `Какие фильтры и параметры доступны в запросе Заказа покупателя?`
- `Нужна последовательность запросов: создать Контрагента и затем создать Заказ покупателя.`

Если ответ агента расходится с документацией, ориентируйтесь на документацию.
