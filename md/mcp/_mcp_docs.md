# MCP-docs

В разделе описан MCP-сервер документации JSON API Remap 1.2. После подключения ИИ-агент может искать ответы по этой документации: находить эндпоинты, поля сущностей, параметры запросов и ограничения.

Сервер не выполняет запросы к пользовательскому аккаунту МоегоСклада. Он только читает документацию.

## Зачем подключать MCP-сервер

- Документация большая, агент не удерживает ее целиком в контексте. MCP не загружает все страницы в чат: агент запрашивает только фрагмент, нужный для текущего заданного вопроса
- Ответы обычно дешевле и быстрее. Приложенные файлы используют токены в каждом следующем сообщении, а MCP возвращает компактный результат
- Агент получает уже найденный фрагмент документации, а не сырой набор файлов, который нужно просматривать целиком
- Локальная копия устаревает после изменений API. MCP-сервер читает актуальную документацию Remap 1.2

## Подключение

Настройки схожи для любого ИИ-агента, который имеет возможность подключать удаленные MCP-серверы.


| Параметр        | Значение                                        |
| --------------- | ----------------------------------------------- |
| **Имя сервера** | `moysklad-docs`                                 |
| **URL**         | `https://mcp.moysklad.ru/doc/api/remap/1.2`     |
| **Авторизация** | Не требуется. Поле токена можно оставить пустым |


### Два варианта подключения MCP-сервера

#### 1. Попросить агента подключить сервер

В чате попросите агента добавить MCP-сервер документации и передайте ему настройки:

- имя: `moysklad-docs`
- URL: `https://mcp.moysklad.ru/doc/api/remap/1.2`
- авторизация не нужна

После добавления проверьте, что сервер появился в списке MCP и включен. Если статус не обновился, перезапустите клиент. При первом обращении разрешите вызов, если агент запросит подтверждение.

#### 2. Ввести настройки самостоятельно

В настройках агента откройте раздел MCP, плагинов или подключений и добавьте новый сервер. Укажите те же параметры:

- имя: `moysklad-docs`
- URL: `https://mcp.moysklad.ru/doc/api/remap/1.2`
- авторизацию и токен не заполняйте

>Пример:
```json
{
  "mcpServers": {
    "moysklad-docs": {
      "url": "https://mcp.moysklad.ru/doc/api/remap/1.2"
    }
  }
}
```

Сохраните настройки и убедитесь, что сервер включен. Если клиент хранит MCP в конфигурационном файле, добавьте туда запись с этими же именем и URL. Если сервер задан и глобально, и в проекте, используется проектная конфигурация.

## Как пользоваться

После подключения достаточно сформулировать задачу в чате. Агент сам найдет нужные фрагменты документации. Чем точнее вопрос, тем устойчивее ответ: укажите сущность, операцию и что должно получиться в результате.

Примеры:

- `Найди в документации Remap 1.2, как создать товар. Нужны путь, метод и обязательные поля.`
- `Какими фильтрами можно выбрать заказы покупателя? Ответ сверь с документацией.`
- `Нужна последовательность запросов: создать контрагента и затем создать заказ покупателя. Опирайся только на документацию Remap 1.2.`

Если ответ расходится с [документацией](https://dev.moysklad.ru/doc/api/remap/1.2/), уточните задачу и попросите агента проверить ее еще раз. Источником истины остается эта документация.
